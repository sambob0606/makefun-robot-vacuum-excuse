One funny excuse from a robot vacuum for missing a spot, picked by a program for make.fun's "The Robot Vacuum's Best Excuse" bounty. The program scores three candidate lines on the judge's own criteria — funny first, then rooted in the vacuum's own world, then landing on first read, then sounding like the vacuum itself — and writes the winner to `/output/entry.txt`. The winner is the cliff-sensor line: the vacuum's sensor mistakes a crumb for the edge of the world, gives it a wide berth, and files a full incident report.

## The winning line

> My cliff sensor mistook that crumb for the edge of the world, so I gave it a wide berth and filed a full incident report.

121 characters, one line, no trailing newline.

## Run it

```sh
python3 main.py
```

It writes the winning line to `/output/entry.txt`, then reads it back and verifies the gate (UTF-8 text, 1 to 140 characters, not only whitespace, exactly one line) before exiting.
